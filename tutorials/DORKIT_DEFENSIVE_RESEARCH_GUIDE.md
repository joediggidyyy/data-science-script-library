# Dorkit Defensive Research Guide

This tutorial adds a defensive-research bridge between the Data Science Script Library and the Dorkit handbook.

## What this guide is for

- Getting started with operator-based search literacy for authorized security review.
- Understanding how to classify findings as exposure signals, not exploitation prompts.
- Connecting search findings to practical data/automation workflows in this library.

## Canonical source in this workspace

- Dorkit handbook source is maintained outside this repository and is not publicly linked here yet.
- Public reference in this repo: [`DORKIT_DEFENSIVE_RESEARCH_GUIDE.md`](DORKIT_DEFENSIVE_RESEARCH_GUIDE.md)

## Suggested learning path

1. Read the handbook sections on operator groups and interpretation workflow.
2. Build a small scoped query set for assets you own or are explicitly authorized to assess.
3. Record findings as structured data (JSON/CSV) and profile the outputs with scripts from this repository.
4. Prioritize remediation actions based on exposure class and repeatability.

## Safety boundary

Use these methods only for systems you own or where you have explicit authorization. Keep the workflow defensive, document findings responsibly, and remediate at the source.
